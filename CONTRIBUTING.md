# Contributing

Thank you for your interest in contributing to Smart Placement Portal!

## How to contribute

1. Fork the repository on GitHub.
2. Clone your fork:
   ```bash
   git clone https://github.com/<your-username>/Smart-Placement-Portal.git
   ```
3. Create a new branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. Make your changes and add tests if applicable.
5. Commit your changes with a descriptive message:
   ```bash
   git commit -m "feat: add example feature"
   ```
6. Push your branch to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
7. Open a pull request against `main`.

## Code style

- Use existing project formatting and conventions.
- Keep changes focused and reviewable.
- Run linting or tests before submitting if available.

## Reporting issues

If you find a bug or want to request a feature, open a GitHub issue with a clear title and description.
